# Support

For installation and configuration help, start with the
[README](README.md) and the guides in [`docs/install`](docs/install/).

For questions and troubleshooting, use
[GitHub Discussions](https://github.com/itsmeares/better-zcp/discussions).
Use an issue for a confirmed, reproducible bug or a focused feature request.

When asking for help, include the panel version, operating system, deployment
method, and sanitized logs. Never post passwords, tokens, private keys, or
unredacted support bundles. Security vulnerabilities belong in the private
advisory flow described in [`SECURITY.md`](SECURITY.md).
